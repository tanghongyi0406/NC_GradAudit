# Reproduction provenance

The frozen data archives, model identifiers, pinned revisions, and adapter paths are machine-readable in `configs/models.json`, `data_archives/SHA256SUMS`, and `adapters/SHA256SUMS`. Paper results and source data are distributed separately from this implementation repository.

The Qwen2-VL and InternVL3 adapter digests uniquely identify the fine-tuned weights used for the reported MedTrinity results. Release verification rejects missing or altered assets.
